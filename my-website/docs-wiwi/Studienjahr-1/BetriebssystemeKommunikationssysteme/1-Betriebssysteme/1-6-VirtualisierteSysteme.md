# 1.6 Virtualisierte Betriebssysteme

## 1.6.1 Grundlagen

Virtualisierung bezeichnet im Kontext von Betriebssystemen das kokrete nachbilden bzw. simulieren eines Hard- oder Softwareobjekts durch ein ähnliches Objekt vom selben Typ mithilfe einer Softwareschicht. 

Dadurch lassen sich virtuell (d.h. nicht physisch) Komponenten wie emulierte Hardware, Software, Datenspeicher, Betriebssysteme oder Netzwerkressourcen erzeugen. Dies ermöglicht das transparente Aufteilen oder zusammenfassen von Computerressourcen - außerdem kann so ein Betriebssystem innerhalb einem anderen ausgeführt werden.
