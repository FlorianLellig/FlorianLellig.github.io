# 3. SAP Fiori Elements

SAP Fiori Elements ist ein Framework zur effizienten Entwicklung von Web-Apps innerhalb des SAP Ökosystems. Anstatt jede Schaltfläche und jedes Tabellenlayout manuell zu entwickeln, nutzt man hier vordefinierte Vorlagen (sog. Floorplans).

## Vorteile von SAP Fiori Elements

### Geschwindigkeit

Apps können in Stunden statt in Tagen oder Wochen erstellt werden, da der Frontend Code minimal bleibt.

### Konsistenz

Da alle Apps auf denselben Vorlagen basieren, sehen sie identisch aus und lassen sich gleich bedienen – das reduziert den Schulungsaufwand für Nutzer.

### Wartungsarm

SAP aktualisiert das Framework im Hintergrund. Neue Design-Standards oder Fehlerkorrekturen werden automatisch übernommen, ohne dass du den Code der einzelnen Apps anfassen musst.
