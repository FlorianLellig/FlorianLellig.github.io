# 2.1.2 - CDS Query Language (CQL)

Die CDS Query Language (CQL) ist die Sprache, mit der Daten aus den definierten Modellen abgefragt werden. Sie ist abgeleitet aus SQL und für die Arbeit mit strukturierten Daten optimiert.

:::note
**Bestandteile des Abschnittes**
- `SELECT from` zur Abfrage von Daten
:::

## `SELECT from`-Statement Inklusive Expands

```sql
SELECT from Authors {
  name,
  books { title } 
}
```

:::info
Diese Syntax erlaubt es, tiefe Verschachtelungen von Datenstrukturen über eine einzige Abfrage zu erhalten
:::

## `SELECT from`-Statement als Pfadausdrücke

```sql
SELECT from Books[author.name = 'Goethe'] { title };
```
:::info
Ähnlich zu WHERE Klauseln in SQL
:::

## `SELECT from`-Statement mit `excluding` Klausel

Ein nützliches Feature für Microservices ist die `excluding`-Klausel. Sie erlaubt es, alle Felder einer Entität auszuwählen, außer den explizit genannten.

```sql
entity PublicBooks as select from Books { * } excluding { purchasePrice };
```
