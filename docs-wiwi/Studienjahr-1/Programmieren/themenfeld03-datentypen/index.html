Themenfeld 3 - Datentypen

info

Dieses Themenfeld wurde nach der Klausur mit Hilfe von KI der Vollständigkeit halber ergänzt.

Arten von Datentypen​

hinweis

Datentypen legen fest, welche Werte eine Variable annehmen kann und welche Operationen darauf erlaubt sind.

Boolesche Datentypen​

  • Wahrheitswerte: true oder false

Numerische Datentypen​

  • Ganzzahlig: byte, short, int, long
  • Gleitkomma: float, double

Alphanumerische Datentypen​

  • char — einzelnes Unicode-Zeichen
  • String — Zeichenkette (Referenzdatentyp)

Komplexe Datentypen​

  • Klassen, Interfaces, Arrays — alle werden als Referenzdatentypen bezeichnet
  • Variablen speichern nicht den Wert selbst, sondern eine Referenz (Speicheradresse)

Deklaration von Variablen und Konstanten​

Variablen​

Eine Variable reserviert einen benannten Speicherplatz für einen veränderlichen Wert.

int alter = 21;
double preis = 9.99;
String name = "Max";
hinweis

Syntax: <Datentyp> <Name> = <Wert>;

Konstanten​

Konstanten werden mit dem Schlüsselwort final deklariert und können nach der Initialisierung nicht mehr verändert werden. Konstante werden per Konvention in GROSSBUCHSTABEN geschrieben.

final double MWST = 0.19;
final int MAX_ANZAHL = 100;

Literale​

Literale sind direkt im Quellcode angegebene Werte.

Numerische Literale​

int dezimal   = 42;       // dezimal
int oktal     = 052;      // oktal (führende 0)
int hex       = 0x2A;     // hexadezimal (0x)
int binaer    = 0b101010; // binär (0b, seit Java 7)
long gross    = 42L;      // long-Literal (Suffix L)

Gleitkomma-Literale​

float  f = 3.14f;   // float-Literal (Suffix f)
double d = 3.14;    // double-Literal (Standard)
double e = 3.14d;   // double-Literal (Suffix d, optional)

Boolean-Literale​

boolean wahr  = true;
boolean falsch = false;

Char-Literale​

char buchstabe = 'A';
char unicode   = 'A'; // entspricht 'A'

String-Literale​

String begruessung = "Hallo Welt";

Text Blocks (seit Java 15)​

Text Blocks ermöglichen mehrzeilige Strings ohne manuelle Zeilenumbrüche.

String json = """
        {
            "name": "Max",
            "alter": 21
        }
        """;

Konvertierung​

Erweiternde Konvertierung (widening)​

  • Automatisch möglich, da kein Datenverlust
  • Reihenfolge: byte → short → int → long → float → double
  • char kann zu int erweitert werden
int i = 100;
long l = i;      // automatisch (widening)
double d = l;    // automatisch (widening)

Einschränkende Konvertierung (narrowing)​

  • Erfordert expliziten Cast, da Datenverlust möglich
double d = 9.99;
int i = (int) d; // expliziter Cast — Nachkommastellen gehen verloren: i = 9
warnung

Bei der einschränkenden Konvertierung können Daten verloren gehen. Der Cast muss bewusst durchgeführt werden.

Arrays​

hinweis

Arrays sind Felder gleichen Datentyps mit einer festen Länge. Die Länge wird bei der Erstellung festgelegt (semidynamisch). Der erste Index ist immer 0.

Deklaration und Initialisierung​

// Deklaration mit new
int[] zahlen = new int[5]; // Array mit 5 int-Elementen (alle 0)

// Deklaration mit Literal
String[] namen = {"Anna", "Ben", "Clara"};

// Zugriff auf Elemente
zahlen[0] = 42;
System.out.println(namen[1]); // Ausgabe: Ben

Länge eines Arrays​

int laenge = zahlen.length; // Attribut length gibt die Anzahl der Elemente zurück

Iteration über ein Array​

for (int i = 0; i < zahlen.length; i++) {
    System.out.println(zahlen[i]);
}
tipp

Arrays starten immer bei Index 0 und enden bei Index length - 1. Ein Zugriff außerhalb dieses Bereichs führt zu einer ArrayIndexOutOfBoundsException.
